# Keyboard Rage Detector 🎯

## Basic Details
### Team Name: Keyboard Rage Detector

### Team Members
- Team Lead: Amrithendu J R

### Project Description
Keyboard Rage Detector is a real-time typing hostility analyzer that measures how aggressively you hit your keyboard. It calculates a live Rage Score from 0 to 100%, visualizes your typing fury with gauges and screen effects, and responds with witty commentary and reactive sounds.

### The Problem (that doesn't exist)
Modern typing tools only count words and mistakes, but they never tell you whether your keyboard is about to become a stress grenade.

### The Solution (that nobody asked for)
Keyboard Rage Detector turns every furious burst, backspace storm, caps lock shout, and frantic key press into a dramatic rage score with neon visuals, sound feedback, and sarcastic judgment.
